# Dependent-Gap

**Dependent-Gap** is a free, community-driven poker casino prototype built on blockchain technology. 

## The Gap - A Chip Whirlpool

The unique feature of Dependent-Gap is the **Gap**—a whirlpool-style table where:
- Players place chips into the gap
- Chips flow through the system and come out as winnings
- Players can cash out their chips with zero hedge fees
- Only gas fees apply to transactions

## Features

- 🎮 Bot practice tables with AI opponents
- 💬 Simulated chat for community engagement
- 💰 Zero hedge fees—transparent, player-friendly economics
- 🔗 Blockchain-based transactions
- 🎯 Dependent gameplay—success depends on choosing the right winners
